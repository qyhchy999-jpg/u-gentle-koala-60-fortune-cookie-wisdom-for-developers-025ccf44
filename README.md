One fortune-cookie line, 92 characters: "Your next bug is already in production. It has been waiting patiently for you since Tuesday." It works as a fortune because it is true and specific — and "since Tuesday" is the detail that makes it land: not "soon", but a weekday that has already passed.

## Entry

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt`. The line is baked into the program, so it runs with no network and writes identical bytes on every run.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then check the output is UTF-8 text of 1 to 120 characters, and run it twice to confirm both runs write the same bytes.
